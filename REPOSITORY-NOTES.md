# Repository preparation notes

This ZIP is a deliberately minimal, public-facing repository package.

- It contains a research overview, citation metadata, and a defensive `.gitignore`.
- It does not include the uploaded archive's benchmark traces, labels, annotations, prompts, embeddings, model outputs, internal audit logs, or manuscript build artifacts.
- It is not a complete reproducibility package and does not claim to be one.
- No manuscript PDF, source data, or publication DOI is included.
- Review the repository's data-rights position before adding any additional artifacts.

The `.gitignore` is a safeguard, not a substitute for reviewing `git status` before every push.
